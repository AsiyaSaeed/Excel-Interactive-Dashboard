# Employee Performance & Working Hours (Interactive Dashboard using MS Excel)
## Project Objective
To create an interactive operations report and dashboard so that managers can track employee working hours, break efficiency, and performance metrics dynamically using custom VBA macro toggle controls and PivotTables.
- <a href="https://github.com/AsiyaSaeed/Excel-Interactive-Dashboard/blob/main/EXCEL%20EMPL%20DASHBOARD.xlsm">Dataset</a>
## Question (KPIs)
- What are the total working hours logged by employees?
- What is the sum of active time spent with customers per employee?
- How can the record count be dynamically adjusted using the spin buttons on each report section?
- How do the custom VBA macro eye icons toggle the chart visibility on and off seamlessly?
